  The AI Smart Image Tag Generator is an AI-powered web application designed to automate image analysis and tagging. It allows users to upload images or capture them using a 
webcam for automatic processing. The system uses YOLOv8 to detect objects and identify important visual elements within an image. BLIP generates meaningful natural-language 
captions describing the image content. Based on detected objects and captions, the application automatically generates relevant keywords and tags. It supports tag generation in 
English, along with image search and storage features. The application simplifies image organization, improves accessibility and helps users efficiently manage and retrieve images 
through an interactive web interface.
